## Lessons

- **A change made on the host is invisible to the repository** — the upload
  ran for a month with the handoff's "what is running" table wrong.
- **A plan built on an audit claim needs its own measurement before code.**
  The EONET plan agreed on 2026-11-13 would have made the data worse; one
  API query on 2026-11-14 showed it.
- **String-compared timestamps make value migrations dangerous.** The #127
  migration was safe only because a test feeds the same raw value through
  the parser and the migration and requires byte-identical output.
